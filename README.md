# DAM Encrypted Media Streaming Backend (Next.js)

Высокопроизводительный бэкенд на **Next.js (App Router)** для передачи медиаконтента (картины Государственного Русского музея, 3D-модели в формате GLB и экскурсионные видео MP4) в **зашифрованном потоковом формате сегментами** с поддержкой деплоя на **Vercel**.

---

## 🔑 Спецификация шифрования и потоковой передачи

- **Алгоритм:** `AES-256-CTR` (Counter Mode — потоковый шифр без оверхеда на паддинг, сохраняет исходный размер байтов).
- **Секретный ключ (по умолчанию):** `hhghghdgfjgfgdahgd` (также настраивается через переменную окружения `ENCRYPTION_KEY`).
- **Ключ шифрования (256 бит):** `SHA-256(ключ)`
- **Вектор инициализации (IV):** 16 байт, передается в заголовке `X-Encryption-IV` ответа.
- **Потоковая передача сегментами:** HTTP `Transfer-Encoding: chunked` с размером сегментов (по умолчанию 64KB для картинок, 256KB для 3D-моделей и 512KB для видео).

## 📡 Эндпоинты API

### 🖼 Картины (Russian Museum Paintings — 700 шт.)

| Эндпоинт | Метод | Описание |
|---|---|---|
| `/painting/info/:id` | `GET` | Метаданные картины в формате JSON (название, автор, пропорции, размеры, эндпоинты). |
| `/painting/image/:id` | `GET` | Зашифрованный поток изображения картины сегментами (AES-256-CTR). |
| `/painting/image/:id?chunk=0&chunkSize=65536` | `GET` | Получение конкретного сегмента изображения по индексу. |
| `/painting/image/:id?raw=true` | `GET` | Исходное незашифрованное изображение (для превью / тестов). |
| `/painting/list` | `GET` | Список картин с пагинацией и поиском (`?page=1&limit=50&q=Куинджи`). |

### 🗿 3D-модели (Russia 3D Models — 34 шт.)

| Эндпоинт | Метод | Описание |
|---|---|---|
| `/model/info/:id` | `GET` | Метаданные 3D-модели в формате JSON (описание, категория, размер, GLB). |
| `/model/file/:id` | `GET` | Зашифрованный поток 3D-модели (.glb) сегментами (AES-256-CTR). |
| `/model/file/:id?chunk=0&chunkSize=262144` | `GET` | Получение конкретного сегмента 3D-модели по индексу. |
| `/model/file/:id?raw=true` | `GET` | Исходная незашифрованная 3D-модель (для прямого тестирования). |
| `/model/list` | `GET` | Полный список всех 34 3D-моделей каталога. |

### 🎥 Видео (MP4 — 5 шт.)

| Эндпоинт | Метод | Описание |
|---|---|---|
| `/video/info/:id` | `GET` | Метаданные видео в формате JSON (название, описание, категория, размер). |
| `/video/file/:id` | `GET` | Зашифрованный поток видеофайла (.mp4) сегментами (AES-256-CTR). |
| `/video/file/:id?chunk=0&chunkSize=524288` | `GET` | Получение конкретного сегмента видео по индексу. |
| `/video/file/:id?raw=true` | `GET` | Исходный незашифрованный видеопоток для стандартного HTML5 плеера. |
| `/video/list` | `GET` | Каталог всех доступных видео. |

### 🌐 Обзор сервиса и Универсальный плеер

| Эндпоинт | Метод | Описание |
|---|---|---|
| `/api/catalog` | `GET` | Сводный статус каталога, общее количество картин, моделей и видео. |
| `/player.html` | `GET` | **Автономная HTML-страница плеера**: вставьте любую ссылку (картина / 3D / видео) для мгновенной дешифрации и воспроизведения. |
| `/` | `GET` | Интерактивный Next.js веб-дашборд с вкладками для всех типов медиа. |

## 📺 Автономная HTML-страница плеера

Файл [player.html](file:///D:/develop/GAN/DAM-backend/player.html) (и [public/player.html](file:///D:/develop/GAN/DAM-backend/public/player.html)) можно:
1. Открыть прямо из бэкенда: `http://localhost:3000/player.html`
2. Открыть локально двойным кликом в любом современном браузере (Chrome, Firefox, Safari, Edge).
3. Вставить любую ссылку (например, `http://localhost:3000/painting/image/2`, `/model/file/1`, `/video/file/4`).
4. Страница автоматически:
   - Определит тип контента (Картина / 3D GLB модель / Видео MP4).
   - Загрузит зашифрованный поток сегментами с отображением прогресса.
   - Дешифрует поток на клиенте с помощью **Web Crypto API**.
   - Отобразит интерактивный результат:
     - **Картина:** изображение высокого разрешения.
     - **3D-Модель:** Google Model Viewer с вращением 360°, освещением и AR.
     - **Видео:** полноценный HTML5 видеоплеер с автовоспроизведением и перемоткой.
